# Mechanics for emergence

The people must be able to build, out of a small set of verbs, what people
have built: property, markets, credit, law, feuds, dynasties, faiths. The
engine should not script any of it (PLAN.md: the engine owns the world, the
model only chooses; record everything, enforce almost nothing social). So the
question for each phenomenon is not "how do we make it happen" but **"what
must be possible, perceivable and remembered for it to happen on its own?"**

For each: the primitives it needs, and whether the world has them.
✓ in place · ◐ partial · ✗ missing · → the version that adds it, or *later*.

## 1. Living off the land

| Needs | Status |
|---|---|
| Food that is scarce, seasonal, and different in kind (berries, game, fish, grain) | ✓ |
| Food that rots, and people who can see it rot | ✓ w10 |
| Ways to keep food: stores, smoking and drying, grain | ✓ w9 |
| A way to a surplus: farms, grain sown again | ✓ w11 |
| Commons that can be ruined by overuse (bushes picked bare die) | ✓ |
| Game that can be overhunted | ◐ herds shrink and regrow; no lasting harm |
| Fish that can be overfished | ✗ *later*: fishing never depletes a shore |
| Shocks: drought, storms, blight, hard winters, wolves | ✓ |

## 2. Property

| Needs | Status |
|---|---|
| Things one carries are one's own | ✓ |
| Buildings with an owner | ✓ |
| Closing a store, shelter or wall to others | ✓ |
| **Crops as property**: a farm its owner can close, and taking from it recorded as taking | ✗ → w14 (a ripe farm was anyone's harvest, and no one remembered who took it) |
| Taking without asking, remembered by victim and witnesses | ✓ w13 |
| Breaking another's building, remembered by witnesses | ◐ owner only → w14 |
| **Handing over a building** (sale, gift, dowry, tribute) | ✗ → w14 |
| **Naming an heir** | ✗ → w14 (inheritance went partner, then first child, automatically) |
| Land claims beyond buildings | ◐ signs, named places and walls; unenforced, as in life before law |

## 3. Exchange and the economy

| Needs | Status |
|---|---|
| Gifts, and the memory of them | ✓ |
| Barter, face to face | ✓ deals |
| Credit: promises of later payment, kept or broken on record | ✓ |
| Money | ✓ possible: any durable, light, wanted thing (a necklace, grain) can serve |
| Labour for hire | ◐ possible as a deal with a promise; no one can verify work except by what is handed over |
| Specialisation that pays: skills that improve yields, and a known reputation for them | ✓ |
| Capital: tools that multiply work and wear out | ✓ |
| A market: a known place and time to trade | ◐ possible (named places, speech); no standing offers *later* |
| Taxation or tribute | ◐ possible as deals backed by force (w13); nothing automatic, by design |

## Built in w14

Crops as property, witnesses to breaking, handing over and bequeathing
buildings, ending a partnership, kin remembering a killer, leaders visible.
And, from the live world's dead: what things weigh, a full load named, and
food eaten on the spot when it cannot be carried.

## Next, in rough order of what they would open up

1. **Dependent children**: families as economic units; inherited advantage.
2. **Fish that deplete a shore**: a second commons to ruin or manage.
3. **Hearsay recorded**: "Tam told you Kora stole", so reputations travel
   beyond witnesses without relying on a person's notes.
4. **Sickness**: care, quarantine, shelter, fear.
5. **Standing offers at a place**: markets that outlast a conversation.
