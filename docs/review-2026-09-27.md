# Review of draft 1, 2026-09-27

One independent adversarial reviewer read the draft 1 plan and a brief
listing its assumptions. Each finding was checked before it was acted
on. Summary of what changed:

1. **The success test could be passed trivially** by comparing against a
   mute bot, and spoilage made gifts nearly free. Changed: a reciprocity
   bot baseline, a speech-off Gemini arm, structured deals, spoil-dump
   gifts ignored. Draft 3 moved from a pass line to detectors plus a
   variety count, and keeps the comparison as a check.
2. **Agents would rarely meet.** 8 agents on 32×32 with sight 5 see
   under one other agent on average. Changed: denser world.
3. **Joint hunting needed two agents deciding on the same tick**, which
   interrupt-driven calling almost never allows. Changed: `hunt` waits.
4. **Probe 1 measured its own leading prompt.** Confirmed by probe 2.
   The "agents are too violent" conclusion was dropped.
5. **The call budget rested on unmeasured numbers**, and the planned
   response cache would never hit. Changed: bots count would-be calls in
   phase 0; interrupts fire on change only; speech wake-ups capped; cache
   dropped.
6. **A bad API day turns a Gemini run into a bot run** that still passes
   every gate. Changed: retry before fallback, runs over 5% fallback
   flagged.
7. **Phone viewing and resuming across days needed design.** Changed:
   job summary page, a `world` branch, a scheduled resume. Now that the
   repo is public, Pages hosts the viewer.
8. **Gemma as a fallback** was expected to break structured output. Its
   answers matched the schema, but it failed 15 of 18 calls, so it was
   removed from the fallback chain anyway.
9. **Week-one gaps**: no plan-step grammar, no event summarising, moves
   and interactions resolved together. All fixed in the plan.

Open after review: the free-tier daily caps, and whether the auditor's
under-$1-a-run cost estimate holds. Both unconfirmed.
